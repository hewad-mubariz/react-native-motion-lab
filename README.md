# react-native-motion-lab

A 14-day React Native motion challenge focused on expressive interactions, advanced transitions, and depth-heavy animation systems.

## About

This repo is where I build animation-first UI experiments using Expo, React Native Reanimated, Gesture Handler, and WebGPU-backed visual effects.

Each prototype is designed to be:

- technically challenging
- visually polished
- reusable as a building block for future apps

## Current demo

- GPU-powered flock simulation
- interactive disturbances via tap gestures
- shape formations (heart, star, moon, text)
- glass-style animated toolbar controls

## Stack

- Expo
- React Native
- React Native Reanimated
- React Native Gesture Handler
- react-native-wgpu
- TypeScript

## Run locally

```bash
yarn install
yarn ios
```

Or start the dev server with:

```bash
yarn start
```

## Goal

Ship one meaningful motion experiment per day and level up animation engineering through deliberate practice.
